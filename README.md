# FCF启动claude code

给 Claude Code 做的 macOS 桌面客户端。后台通过公司 FCF 中转启动的 `claude`（`~/.fcf/bin/claude`）运行，技能、钩子、插件、记忆、账号和终端里完全一致，只是把交互换成了窗口界面。

## 安装

1. 到 [Releases](../../releases) 下载 `FCF-Claude-Code-<版本>.dmg`。
2. 打开后把「FCF启动claude code」拖进「应用程序」。
3. 第一次打开如果提示「无法验证开发者」：在「应用程序」里右键这个 App →「打开」→ 再点「打开」。

需要：macOS 14 及以上；本机已装好 FCF 并能在终端里用 `claude`。

## 主要功能

- **启动检查**：每次打开先确认 FCF 已安装、已登录、Claude 由 FCF 中转启动；没就绪就在内置终端里运行 `fcf` 完成配置。FCF 有新版本时由你决定升不升。
- **对话**：流式回复、可折叠的思考过程、工具步骤活动轨（长任务自动折叠）、选择题 / 权限确认卡片、停止回复。
- **附件与产物**：粘贴或拖入文件、图片；每轮回复新建或修改的文件以卡片展示，可快速查看、在访达中显示。
- **对话管理**：按文件夹分组、搜索、置顶、重命名、删除（移到废纸篓）、导出 Markdown。
- **斜杠命令**：技能和 Claude Code 命令照常可用；`/status` `/usage` `/stats` 等终端界面专用的命令由客户端实现。
- **状态与统计**：账号、代理、MCP 状态；5 小时 / 本周额度；活跃热力图和每天 tokens。
- **设置中心**：模型、权限规则、环境变量、插件、MCP、技能、子代理、自定义指令、钩子、CLAUDE.md 与记忆、配置原文、运行诊断。
- **外观主题**：16 套预置配色（GitHub、Dracula、Nord、Solarized 等），可自定义强调色。

## 从源码构建

```bash
./build.sh
```

产出 `build/FCF启动claude code.app`，以及 `build/` 下的 dmg 和 zip 安装包。只用系统自带的 Swift 工具链（Xcode 命令行工具），没有第三方依赖。
